# 独立空闲下标栈：修改与复测

本次将 `m_slot_map.h` 的槽内空闲链表替换为 `std::vector<SizeType>` 空闲栈。
保持后删先用：删除时 push_back，复用时读取 back，构造成功后才 pop_back。
新增槽位前按倍数预留空闲数组容量，复制后也保证其 capacity 不小于槽位数量，
因此容器的删除路径不需要分配内存，保留 `erase() noexcept`。

接口、代际失效机制及代际耗尽后停用槽位的规则保持原样。
具体头文件变更见 [change.patch](change.patch)。

## 验证

- Release 与 ASan/UBSan 构建均通过 3 个 CTest 测试。
- 原有测试覆盖槽位复用、旧 key 失效、范围遍历、复制/移动、对象生命周期和构造异常。
- 新增测试禁止内存分配，验证原容器、密集/稀疏副本、赋值和移动后的删除；并逐步注入分配失败，检查追加和复制赋值的异常保证。
- 头文件独立使用测试及 Release 基准 smoke 通过；下列正式基准的数量、校验和及内存释放检查通过。

## 方法

修改前后在同一机器、同一编译器及 `-O3 -DNDEBUG -std=gnu++17` 下分别构建，顺序运行。
每种类型初始 1,000,000 个元素，1 轮预热、7 轮正式计时，表格取中位数。
每轮 custom/dod 交替执行顺序；前后沿用同一基准程序、输入规模和随机种子。
两个版本均使用当前项目内已加入跳过删除槽位检查的 dod，未修改 dod。
计时与内存统计分别运行；没有锁定 CPU 核心或频率，前后进程的分配器/缓存状态不完全相同。
下面是本机这组工作负载的结果，不代表完整网格算法的耗时。

## 回填刚删除的半数

单位 ns/插入元素；插入包含元素构造，Vertex/Dedge 包含邻接 vector 分配。

| 类型 | 自定义修改前 | 自定义修改后 | 加速倍数 | dod（前一轮） | dod（后一轮） |
|---|---:|---:|---:|---:|---:|
| Vertex | 109.294 | 55.727 | 1.96× | 72.216 | 60.525 |
| Dedge | 110.854 | 55.909 | 1.98× | 59.802 | 59.792 |
| Halfface | 100.418 | 33.101 | 3.03× | 26.935 | 28.327 |
| Cell | 104.788 | 32.466 | 3.23× | 26.800 | 26.363 |

回填改善约 1.96–3.23 倍。修改后 Vertex/Dedge 在这一项接近 dod；Halfface/Cell 仍慢于 dod。
这支持将空闲下标连续存放的方案，但没有硬件计数器数据，不能仅凭此结果量化缓存未命中或流水线等待的变化。

## 其他操作的取舍

每格为修改前 → 修改后（耗时变化）。单位 ns/元素，删插对按一整对计。

| 操作 | Vertex | Dedge | Halfface | Cell |
|---|---:|---:|---:|---:|
| 从空容器批量插入 | 23.710 → 23.218（-2.1%） | 22.950 → 21.798（-5.0%） | 7.311 → 7.624（+4.3%） | 7.165 → 7.484（+4.5%） |
| 随机删除半数 | 94.444 → 96.240（+1.9%） | 104.366 → 92.303（-11.6%） | 15.087 → 25.206（+67.1%） | 14.633 → 24.194（+65.3%） |
| 随机删一个、插一个 | 263.756 → 230.634（-12.6%） | 325.519 → 204.547（-37.2%） | 50.840 → 64.904（+27.7%） | 53.442 → 60.156（+12.6%） |
| 密集复制 | 16.523 → 16.961（+2.7%） | 16.743 → 15.716（-6.1%） | 2.303 → 2.427（+5.4%） | 2.373 → 2.355（-0.8%） |
| 随机 get | 10.208 → 9.430（-7.6%） | 8.516 → 7.338（-13.8%） | 7.830 → 8.395（+7.2%） | 8.125 → 8.034（-1.1%） |

**需要注意的退步：** Halfface/Cell 随机删除约慢 65–67%，逐次删插约慢 13–28%。
因此这一版本适合继续评估批量编辑收益，不能据回填结果认定所有编辑操作都更快。
其余小幅变化也受运行波动影响；完整四分位区间、极值及其他操作见前后统计文件。

## 内存代价

统计容器及元素成员实际请求的堆字节数，排除外部 key 数组、分配器取整及栈对象；不是 RSS。

| 类型 | 密集时修改前（MiB） | 修改后（MiB） | 增量（MiB） |
|---|---:|---:|---:|
| Vertex | 117.406 | 121.406 | 4.000 |
| Dedge | 94.147 | 98.147 | 4.000 |
| Halfface | 72.000 | 76.000 | 4.000 |
| Cell | 72.000 | 76.000 | 4.000 |

本次每个容器新增 4 MiB 预留空间，对应 1,048,576 个 32 位下标。
全部删除后数组容量仍保留。容器栈对象由 32 字节增至 56 字节；key 仍为 8 字节。
本机这四种元素的槽位因对齐填充没有随 next_free 字段删除而缩小。
内存统计中，自定义容器删除至 50%、10% 和全部删除的各阶段分配次数均为 0。
